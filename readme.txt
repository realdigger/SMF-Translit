[b]Translit 1.0.4[/b]

Converts Latin keyboard input to Cyrillic while composing a message. Buttons also convert selected text or the whole message in either direction.

[b]Compatibility[/b]
[list]
[li]SMF 2.0.x (PHP 5.4 or later)[/li]
[li]SMF 2.1.x (PHP 7.1 or later)[/li]
[/list]

[b]After installation[/b]
Open the full message editor and use the Translit panel below the text field. No settings or permissions are required. Removing the mod deletes its files and hooks, without changing forum posts.
