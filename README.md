# Translit for SMF

- **Package:** Translit
- **License:** [MIT](LICENSE)
- **Compatible with:** SMF 2.0.x and 2.1.x
- **Languages:** English and Russian
- **Core edits:** none, integration hooks only
- **Current package version:** 1.0.4

Translit converts Latin keyboard input into Cyrillic while composing a forum message. It also converts selected text or the whole message in either direction.

## Installation

Download the latest `tar.gz` package from [Releases](https://github.com/realdigger/SMF-Translit/releases) and install it through the SMF Package Manager. No settings or permissions need to be changed. Uninstalling removes the mod's files and hooks; it does not alter forum posts.

## Description

The Translit panel appears below the message editor when creating or editing a post. Click **enable** to transliterate as you type, or use the conversion buttons for existing text. On SMF 2.1, enabling transliteration switches SCEditor to source mode; disabling it restores the previous visual mode. The package uses integration hooks and does not modify SMF core files.

## Compatibility

- SMF 2.0.x: PHP 5.4 or later.
- SMF 2.1.x: PHP 7.1 or later.

## Установка

Загрузите актуальный архив `tar.gz` со [страницы релизов](https://github.com/realdigger/SMF-Translit/releases) и установите его через менеджер пакетов SMF. Дополнительные настройки и права не требуются. При удалении мода удаляются его файлы и хуки; сообщения форума не изменяются.

## Описание

Панель транслитерации появляется под редактором при создании или изменении сообщения. Нажмите **включить**, чтобы преобразовывать вводимую латиницу в кириллицу, либо используйте кнопки для перевода выделенного текста или всего сообщения. В SMF 2.1 при включении транслитерации SCEditor переключается в текстовый режим, а при выключении восстанавливает прежний визуальный режим. Мод использует хуки интеграции и не изменяет файлы ядра SMF.
